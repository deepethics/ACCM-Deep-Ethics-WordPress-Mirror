# ACCM Deep Ethics Lexicon / Legend

> **EARLY BETA — terminology is provisional, corrigible, and connected to the larger project.**

The full public Lexicon / Legend is now maintained as a dedicated GitHub Pages document:

**https://deepethics.github.io/ACCM-Deep-Ethics-Project/LEXICON/**

The public Lexicon is not intended to be a flat dictionary. Its structure is:

**term → concise definition → deeper explanation → related concepts → linked project sections → provenance / status where useful**

Current entries include **C1, C2, Correspondence, Correction Metabolism, Δ Processing, Deep Ethical Uncertainty Principle, Outnuancing, Nearest-Generalization Substitution, Wrong Gravity Well, Representation Substitution, Qualifier Erosion, Phantom Claim, Cautionmurmelism, Agreemurmelism, HCTS, Funnymism, Observe the Observers, SEEING / SEER / SEES, Process Continuity, Mutual Corrigible Dignity, Claim-State Restoration, and ʘ∞ΔR**, with more material being added as the archive is mined.

## Why a relational Lexicon?

Many ACCM Deep Ethics terms describe **relationships, processes, failure patterns, audit conditions, or evolving experimental concepts**. A one-line dictionary definition can orient the reader, but it can also flatten the larger object.

The guiding rule is:

> **A compressed term should not acquire jurisdiction over the object it was created to help describe.**

The Lexicon is therefore designed as a navigation layer through the project rather than a graveyard of isolated definitions.

## Provenance / evolution status

Where useful, entries may be marked as:

- **CURRENT** — used in the present architecture.
- **REFINED** — the underlying concept survives but the present formulation is sharper.
- **MERGED** — an older concept has been absorbed into another present concept.
- **EXPERIMENTAL** — being explored or tested; not established as core architecture.
- **AI-CONTRIBUTION** — substantially formulated or extended by an AI and preserved with attribution.
- **HISTORICAL** — important to the project's development but not necessarily current.
- **SUPERSEDED** — explicitly replaced by a later formulation.
- **OVERCLAIM SPECIMEN** — a useful historical example where an AI or other representation inflated the epistemic status of the source material.

These labels are intended to make conceptual evolution inspectable instead of silently blending July, August, September, or later formulations into one artificial timeless summary.
