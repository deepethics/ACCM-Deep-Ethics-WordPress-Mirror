# Experiments and Specimens

> **BETA — trial, error, replication, correction**

This section will hold experiments, behavioral specimens, cross-model comparisons, protocols, and tests relevant to the ACCM Deep Ethics Project.

The aim is not to make a taxonomy true by finding examples that fit it. Experiments should also be capable of exposing weak categories, failed predictions, alternative explanations, context dependence, and places where the project itself has transformed the object incorrectly.

Where practical, experimental records should distinguish observation from functional interpretation, computational hypothesis, and mechanistic claim.

Failed experiments and disconfirming results can be valuable project data.
